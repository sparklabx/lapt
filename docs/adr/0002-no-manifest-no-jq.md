# No package-ownership manifest, no jq dependency

lapt keeps no *global* database of installed files or which package owns what. Bin/share exposure is undone at `remove` time via a small per-package record, `opt/<pkg>/.lapt-exposed` — a flat list of paths `assemble` wrote, scoped to and deleted with that package (see ADR-0008; a global shared-dir scan was tried first and rejected as O(everything ever exposed) per removal). `lapt list` re-derives state by reading each `opt/<pkg>/.lapt-version`. An earlier design kept a jq-parsed JSON manifest for richer version tracking; dropped because the only things worth tracking — a version+timestamp and an exposure list — are both scoped to one package and covered by tiny key=value/flat-list files living inside that package's own `opt/<pkg>/`, not a global manifest file, a jq dependency, or the staleness risk of tracked state drifting from the filesystem it describes.
